# 《Agent 系统如何可靠上线》重写大纲

正文：`content/posts/agent-sre-slo-release-recovery.md`

研究核对日期：2026-10-22。

## 写作定位

面向已有 Agent 原型、准备接入真实业务写操作的后端工程师、平台工程师和技术负责人。以一个采购任务贯穿，回答三个问题：什么结果值得承诺，什么证据允许发布，故障后凭什么继续执行。

原稿覆盖了 SLO、告警、灰度和恢复，但章节之间的推导较弱，主要依赖 SRE 实践资料，缺少 Agent 重复运行可靠性的研究依据，也没有充分解释未知副作用何时允许重试。新版用任务契约连接这些机制，并明确论文结论、工程推导与示例数据的边界。

## 正文大纲

1. **为什么离线高分还不能证明系统可靠**
   - 开场事故：ERP 已下单、回执丢失、Worker 重启后重复采购。
   - τ-bench：数据库终态验收、`pass^k` 与 `pass@k` 的差异。
   - 可靠性论文：一致性、鲁棒性、可预测性与安全性。
   - MAST：失败应沿系统设计、协作和验证过程诊断。
   - 推导决策语义、执行一致性与服务交付三个工程层面。
2. **先把用户承诺写成可以验收的任务契约**
   - 确定准入条件、服务起点、截止时间、成功证据和接管方式。
   - 业务结果与过程约束共同验收。
   - 区分自动完成、合规拒绝与人工接管。
3. **长任务的 SLO，难点在分母和结算时点**
   - 卡住的任务必须进入分母。
   - 按接收批次观察，等任务到截止点后结算。
   - 区分按截止时间统计的滚动窗口与按接收时间统计的批次。
   - 分开保存按时完成事实和最终恢复结果。
   - 区分结果 SLI、诊断信号、自动化效果与安全事件。
4. **错误预算怎样变成真实的行动规则**
   - 用教学数据推导允许失败量与燃烧率。
   - 解释滚动窗口、流量变化和低样本量的限制。
   - 将多窗口告警映射为值班、限制写入和暂停灰度。
   - 严重安全事件不与一般可用性预算交换。
5. **一次 Agent 发布需要通过哪些验证**
   - 发布配置包括工作流、模型、提示、工具、策略、检索和验收器。
   - 用业务正确性、重复运行、扰动、故障与恢复构建验证矩阵。
   - 影子流量隔离副作用。
   - 灰度任务稳定分组、同期对照、等待成熟结算。
   - 用零失败的单侧上界解释小样本不能证明高可靠性。
6. **超时之后，为什么不能直接重试**
   - 区分任务状态与动作状态，引入 UNKNOWN。
   - 根据 RIFL 解释稳定动作身份、完成记录、原子性和保留期。
   - 查询不到时检查读一致性、在途请求与接收方幂等保证。
   - 无法自动核对时明确人工接管边界。
7. **回滚版本、补偿业务和恢复数据要分别设计**
   - 回滚不撤销已发生动作。
   - 用 Sagas 解释业务补偿及其局限。
   - 旧快照恢复后要重建外部事实。
   - 分别验收查询恢复、对账完成和自动写入恢复。
8. **把恢复能力变成一场可以重复执行的实验**
   - 注入回执丢失、Worker 重启、读延迟、重复回执和旧快照恢复。
   - 每个注入点对应明确验收条件。
   - 补充去重记录提前过期的反例。
   - 输出未决动作、重复副作用和实际恢复时间。
9. **把这些机制放进同一条运营流程**
   - 业务契约 → 结果证据 → SLO 与事件 → 发布/止损 → 核对恢复 → 回归验证。
   - 给出从任务台账到恢复验证的渐进落地顺序。

## 研究资料与论据分工

| 文献 | 主要用途 | 使用限制 |
| --- | --- | --- |
| τ-bench，2024 | 终态验收、重复运行稳定性 | 基准环境不等于生产流量 |
| Towards a Science of AI Agent Reliability，2026，v3 | 四维可靠性框架 | 不把论文指标直接当企业 SLO |
| Why Do Multi-Agent LLM Systems Fail?，2025，v3 | 系统设计、协作与验证失败分类 | 不外推单 Agent 的故障占比 |
| Implementing Linearizability at Large Scale，SOSP 2015 | 请求身份、完成记录、重复执行处理 | 依赖协议、持久化及生命周期条件 |
| Sagas，SIGMOD 1987 | 长事务与业务补偿 | 补偿不等于完全逆转现实影响 |
| Google SRE Workbook 三章 | SLO、燃烧率、灰度发布 | 工程实践资料，非 Agent 实验论文 |

完整链接、论文作者和逐项适用边界见正文末尾。99% SLO、10 分钟截止时间、预算数字及灰度样本均为教学设定。演练是方案，未声称已执行。
