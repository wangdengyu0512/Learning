## 沿着事件看清协作过程

1. **发现与关联。** 无人机巡检、物联传感器和业务系统提供线索，DataOS 关联位置、时间、事件与资源，形成统一的事件信息。
2. **研判与规划。** 巡查识别员识别异常，风险研判员判断影响，处置协调员将处置目标拆成有依赖关系的任务，明确责任与完成条件。
3. **执行与汇总。** 资源匹配员与工单派发员协作，数字员工通过 AgentOS 提供的运行、权限和工具能力执行原子任务，再将执行结果汇总给处置协调员。
4. **部门与现场衔接。** 责任部门接单并组织现场人员和车辆作业；数字员工持续传递任务、证据与状态，进度督办员跟踪进展并推动超时升级。
5. **核验与闭环。** 处置核验员检查回传证据和完成条件，业务负责人确认闭环。核验不通过时回到协调员重新规划或分派，结果反馈到事件记录。

## 七类数字员工在整体图中如何分工

| 数字员工 | 主要职责 |
| --- | --- |
| 巡查识别员 | 从感知线索中识别问题并形成事件候选 |
| 风险研判员 | 结合现场与业务信息研判风险和优先级 |
| 处置协调员 | 制定执行规划、拆分任务、汇总结果并组织重规划 |
| 资源匹配员 | 匹配人员、车辆、设施与可用资源 |
| 工单派发员 | 形成工单并衔接责任部门和执行任务 |
| 进度督办员 | 跟踪状态、催办与推动异常升级 |
| 处置核验员 | 检查证据与完成条件，反馈通过或返工结果 |

数字员工负责信息处理和任务协作，部门承担业务责任，现场人员完成实际作业。图中的跨部门、跨层级交接同时展示任务流向和结果回传，帮助理解谁规划、谁执行、谁确认。
